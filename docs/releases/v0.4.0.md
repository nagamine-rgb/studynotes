## StudyNotes v0.4.0

### ダウンロード
- **Windows**：`StudyNotes_0.4.0_x64-setup.exe`
- **Android**：`StudyNotes_0.4.0_android.apk`（前の版に上書きでインストールできます）

### 変更点
- **表を UpNote のように作れるように**
  - 行の頭で `/` を打つと「表 / 2x2 … 10x10」から選んで入れられる（`/3x4` のように行×列の指定も可）。書式ツールバーの［表］は 3×3
  - 編集画面でも表はマス目で表示。セルをクリックしてそのまま書ける（Tab で次のセル、最後のセルで Tab を押すと行が増える）
  - 右クリックで 行・列の追加／削除、左・中央・右揃え、表の削除
- **セルの結合**：セルをドラッグで選んで右クリック →［セルを結合］。［結合を解除］で元に戻る
  - 結合した表だけ HTML の `<table>` で保存します（ほかの表は今までどおり普通の Markdown の表）
- **表のセルに画像**：セルの編集中に貼り付け／ドロップ。右下のつまみや「小・中・大」で大きさを変えられ、列の幅も画像に合わせて広がる
- 暗記モードでも結合した表・セルの画像を表示し、セルの中のキーワードも隠せる
