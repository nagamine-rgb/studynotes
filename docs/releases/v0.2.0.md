## StudyNotes v0.2.0

### ダウンロード
下の **Assets** から `StudyNotes_0.2.0_x64-setup.exe` をダウンロードして実行してください（通常はこちら）。`.msi` は企業などで一括配布する場合向けです。

> 署名のないアプリのため、初回は Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。

### 主な機能
- ノートは普通の .md ファイル。フォルダ構造のエクスプローラー、Ctrl+P のノート検索、全文検索、ピン留め
- `[[ノート名]]` のリンク（候補表示、名前を変えると自動更新、バックリンク）
- 左右2画面表示（Ctrl+クリックで反対側に開く）
- 暗記モード：`==キーワード==` と `{{穴埋め}}` を塗りつぶし、クリックや Space で1つずつ表示
- 画像の貼り付け・取り込み（attachments に保存、同じ名前でも上書きしない）
- AI：誤字・表記・内容のチェックと、ノートを参照したチャット（OpenAI / DeepSeek / Gemini / Claude / OpenAI互換）

### v0.2.0 の変更点
- **書いたまま整形表示（ライブプレビュー）**：カーソルのある行だけ記号が見え、ほかの行は見出し・強調・リンク・チェックボックス・画像を整形して表示。閲覧モードは廃止
- **書式ツールバー**：本文の下に、見出し・太字・キーワード・穴埋め・リスト・チェック・リンク・画像・表などのボタン
- **AIパネルの整理**：上部の［AI］ボタン（Ctrl+Shift+A）1つで開閉し、クリックしているペインのノートが対象。チェック結果はノートごとに保持
- **AIチャット**：要約・説明・確認問題づくりのワンタッチボタン、回答をノートに挿入、［履歴をクリア］
- モデル一覧の［一覧を更新］で、取得した全モデルをプルダウンから選べるように修正
- 空のリスト項目で Enter するとリストを抜けるように
- 同じノートを左右に開いたとき、片方の編集をもう片方に即反映
- 不具合修正：ウィンドウを閉じられない／編集中に「ほかのアプリで変更されました」と誤って表示される
- ショートカット変更：エクスプローラーの表示切替は Ctrl+Shift+E（Ctrl+B は太字）
