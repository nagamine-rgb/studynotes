# StudyNotes 仕様設計書

テーマ：**とてもシンプル。でも学習に必要な機能はすべて入ったノートアプリ**

| 項目 | 内容 |
| --- | --- |
| 対象OS | Windows 10 / 11（64bit） |
| 形式 | デスクトップアプリ（Tauri 2、インストーラーは NSIS / MSI） |
| 利用者 | 個人（1人・1台）。同期はOneDriveなどのフォルダ同期に任せる |
| データ | 普通の `.md` ファイル。アプリがなくてもメモ帳やObsidianで開ける |

│ ▾ 英語     │ ・abandon ＝ 見捨てる     │ ・if＋過去形              │ とき │

- 左：エクスプローラー（幅 180〜480px、ドラッグで変更、Ctrl+Shift+E で表示切替）
- 中央：ノートペイン 1枚 または 2枚（左右）。境界線はドラッグで幅変更、ダブルクリックで 50:50
- 中央下：書式ツールバー（フォーカスしているペインに効く）
- 右：AIパネル（幅 360px。左端のドラッグで 280px〜画面の6割まで変更、ダブルクリックで元の幅）。ツールバーの［AI］（Ctrl+Shift+A）で開閉。「チェック」「チャット」の2タブ。開くとき設定によりエクスプローラーを自動で畳む
- **フォーカスしているペイン（上端が青い線）が、書式ツールバー・AI・ショートカットの対象**
- 同じノートを左右両方に開いた場合、片方での編集はもう片方に即座に反映される
- テーマ：ライト / ダーク / システムに合わせる

## 2. ノート（.md）

### 2.1 保存
- 1ノート = 1ファイル（UTF-8、改行LF、拡張子 `.md`）
- 自動保存：最後の入力から 500ms 後。保存ボタンはない
- 外部（エクスプローラーや別アプリ）での変更を監視し、ツリーと開いているノートに反映
  - 開いているノートに未保存の変更がある時に外部変更が来たら、アプリ側の内容を優先して上書き保存する前に確認ダイアログを出す
- 先頭に任意で YAML フロントマター（`---` で囲む）。アプリが読むキー：
  - `mask: highlight, bold, cloze`（このノートで隠す対象。省略時は設定値）

### 2.2 表示モード（ペインごと）

| モード | 内容 | 切替 |
| --- | --- | --- |
| 編集（ライブプレビュー） | CodeMirror 6。カーソルのある行だけ `#` `==` `[[ ]]` などの記号を表示し、ほかの行は整形して表示する（見出しの大きさ、強調、リンク、箇条書きの・、チェックボックス、区切り線、画像） | 通常はこちら |
| 暗記 | 整形済みの読み取り専用表示で、キーワードを塗りつぶす | ペインの［暗記］または Ctrl+M |

- ノートを開いただけではカーソルを入れない（すべての行が整形表示になる）。新規作成したノートはカーソルを入れる
- 空のリスト項目で Enter を押すとリストを抜ける。リスト項目の途中で Enter を押すと次の項目が続く
- チェックボックスはクリックで完了／未完了を切り替える

### 2.3 使える記法
CommonMark＋GFM（表・チェックリスト・取り消し線）に加えて：

| 記法 | 意味 |
| --- | --- |
| `[[ノート名]]` / `[[ノート名\|表示名]]` / `[[ノート名#見出し]]` | ノートへのリンク |
| `![[画像.png]]` / `![[画像.png\|300]]` | 画像の表示（幅指定可） |
| `==キーワード==` | 強調。暗記モードで隠れる |
| `{{答え}}` | 穴埋め。暗記モードで「＿＿＿」として隠れる |
| `**太字**` | 太字。設定で「暗記モードで隠す」をONにした場合のみ隠れる |

## 3. リンク

- 編集中に `[[` と打つとノート名の候補を表示（あいまい検索、↑↓とEnterで確定）
- リンク先の解決：ノートのファイル名（拡張子なし、大文字小文字を区別しない）で探す。同名が複数あれば、同じフォルダ → 浅い階層 の順で優先。`[[英語/単語]]` のようにフォルダ付きでも書ける
- 開き方

| 場所 | 同じペインで開く | 反対側のペインで開く |
| --- | --- | --- |
| 編集画面の整形表示されたリンク | クリック | Ctrl+クリック |
| 編集画面の記号が見えている行のリンク | Ctrl+Enter（カーソルがリンク上） | Ctrl+クリック |
| 暗記モードのリンク | クリック | Ctrl+クリック |
| エクスプローラー・検索結果 | クリック | Ctrl+クリック |

- 存在しないノートへのリンクは灰色の点線。クリックすると、リンク元と同じフォルダにそのノートを作って開く
- ファイル名を変えたら、そのノートを指す全リンク（`[[旧名]]` `[[旧名|…]]` `[[旧名#…]]`）を新しい名前に書き換える
- 各ノートの末尾に「バックリンク（このノートを参照しているノート）」を一覧表示

## 4. 2画面表示

- ツールバーの「2画面」または Ctrl+\ で 1画面 ⇔ 2画面
- Ctrl+Tab で左右のペインを切り替え
- 各ペインに履歴：Alt+← / Alt+→ で戻る・進む
- 終了時の状態（左右のノート、モード、幅、開いていたフォルダ）を `.studynote/workspace.json` に保存し、次回起動時に復元

## 5. 暗記モード

- 対象（`==`・`{{}}`・設定で太字）を塗りつぶして表示。文字の幅は保つ
- 塗りつぶしをクリック → その1つを表示（点線枠）。もう一度クリックで隠す
- ペインの下部に操作バー：進み具合（例：3 / 12 表示中）、「次を表示（Space）」「すべて表示」「すべて隠す」「編集に戻る」
- 暗記モードは読み取り専用（誤編集防止）。画像も表示する
- 編集中に文字を選んで Ctrl+H（または書式ツールバーの✎）→ `==` を付ける。もう一度押すと外す

## 5.1 書式ツールバー

本文の下に常に表示し、フォーカスしているペインに効く。押してもカーソル位置・選択は失わない。

| ボタン | 動き |
| --- | --- |
| H1 / H2 / H3 | その行を見出しにする（同じ段階をもう一度押すと外す。リスト記号は外す） |
| B / I / S | 太字 `**` ／斜体 `*` ／取り消し線 `~~`（選択範囲を囲む・外す。選択がなければ記号の間にカーソル） |
| ✎ キーワード | `==…==`（暗記で隠れる） |
| { } 穴埋め | `{{…}}`（暗記で隠れる） |
| 箇条書き／番号付き／チェックリスト／引用 | 選択した行の先頭に `- ` `1. ` `- [ ] ` `> ` を付ける・外す |
| リンク | `[[]]` を入れてノート名の候補を表示（文字を選んでいればそれをリンクにする）。Ctrl+K |
| 画像 | ファイルを選んで attachments に取り込み、`![[…]]` を挿入（複数可） |
| 表 | 3×3 の表を入れて左上のセルを編集状態にする（大きさを選ぶときは本文で `/`。7.1） |
| コード／コードブロック／区切り線 | ひな形を挿入 |
| 元に戻す／やり直し | Ctrl+Z ／ Ctrl+Y |

## 6. エクスプローラー

- 開いているノート用フォルダ（以下「ノートフォルダ」）の中身をツリー表示。`.md` と画像だけ表示し、`.` で始まるフォルダは隠す
- 上部：絞り込み欄（ファイル名の部分一致）／「新規ノート」「新規フォルダ」「すべて折りたたむ」
- クリックでフォルダ開閉・ノートを開く。開いているノートは強調
- 右クリックメニュー：新規ノート／新規フォルダ／名前の変更（F2）／削除（Delete、ごみ箱へ）／反対側のペインで開く／ピン留め・解除／Windowsエクスプローラーで表示
- ドラッグ＆ドロップでフォルダへ移動（リンクはファイル名で解決するので壊れない）
- 下部に「ピン留め」と「最近開いたノート（10件）」
- Ctrl+P：ノート名で即ジャンプ（クイックスイッチャー）
- Ctrl+Shift+F：全ノートの全文検索（結果をクリックでその行へ。Esc でツリーに戻る）

## 7. 画像

- 編集中に Ctrl+V（スクリーンショット等）／画像ファイルをドラッグ＆ドロップ／書式ツールバーの［画像］ → 保存して `![[ファイル名]]` を挿入。編集画面のまま本文中に表示される
- 保存先はノートフォルダ直下の `attachments/` 1か所。**上書きは絶対にしない**
  1. 同じ名前がなければ元の名前で保存（クリップボード画像は `画像_YYYYMMDD_HHMMSS.png`）
  2. 同じ名前があり中身も同じ（SHA-256一致）なら保存せず既存ファイルを参照
  3. 同じ名前で中身が違えば `名前 (2).拡張子`、`(3)`… と空き番号で保存
- 対応形式：png / jpg / jpeg / gif / webp / svg / bmp
- 表示：指定がなければ本文の幅いっぱい。右下のつまみのドラッグ、またはクリックで出る「小（本文の1/3）・中（2/3）・大（幅いっぱい）」で大きさを変え、`![[画像.png|幅px]]` として保存する
- ダブルクリック（またはメニューの「開く」）で、Windows に関連付けられた画像ビューワーで開く

## 7.1 表

UpNote のように、マス目のまま直接書ける表。

- **入れ方**：行の頭で `/` を打つと「表 / 2x2 … 10x10」の候補が出る（`/table`・`/表` でも同じ。`/3x4` と打てば 3行×4列）。書式ツールバーの［表］は 3×3。入れると左上のセルにすぐ書ける
- **表示**：編集画面でも表はいつもマス目で表示する（1行目は見出し行として太字・薄い背景）。セルの中の書式（`==` `**` `[[リンク]]` など）も整形して表示する
- **セルの編集**：セルをクリックするとそのセルだけ入力欄になる
  - Tab／Shift+Tab：次／前のセル（最後のセルで Tab → 行を追加）
  - ↑（先頭で）／↓（末尾で）：上下のセル。表の端なら表の外へ
  - Enter：セルの中で改行（保存は `<br>`）。Esc または Ctrl+Enter：表の外（表の下の行）へ
  - ほかのセルや表の外をクリックすると確定
- **右クリックメニュー**：上／下に行を追加、左／右に列を追加、行を削除、列を削除、左揃え／中央揃え／右揃え（列ごと）、表を削除
- **セルの結合**：セルをドラッグ（または Shift+クリック）で選び、右クリック →［セルを結合］。中身は改行でつなぐ。結合したセルを右クリック →［結合を解除］。結合をまたぐ選択は、結合全体を含むように広げる
- **画像**：セルの編集中に貼り付け／ドロップすると attachments に保存して `![[画像.png|200]]` を入れる（最初は幅200px）。本文の画像と同じく、右下のつまみのドラッグ、クリックで「小（120px）・中（240px）・大（400px）・開く」、ダブルクリックでビューワー。列の幅は画像に合わせて広がる
- **保存形式**
  - 結合のない表：普通の Markdown（GFM）の表。セルの中の `|` は `\|`（画像の幅 `![[a.png\|200]]` も同じ。アプリが自動で書き換える。Obsidian と同じ書き方）
  - 結合のある表：その表だけ HTML の `<table>`（`rowspan`／`colspan`、1行目は `<th>`）。中身の Markdown（`==` や `![[ ]]`）はそのまま書く。すべての結合を解除すると Markdown の表に戻る
  - ノート中のほかの HTML は今までどおり表示しない（StudyNotes が書く形の `<table>` だけを表として読む）
- 暗記モードでも表（結合・画像を含む）を表示し、セルの中の `==` `{{}}` も隠せる
- 元に戻す（Ctrl+Z）は表の変更ごとに戻る

## 8. AIチェック

### 8.1 使い方
1. ツールバーの［AI］（または Ctrl+Shift+A）→ 右端にAIパネルが開く。対象は**フォーカスしているペインのノート**で、パネル上部に「対象：ノート名（左／右）」と表示する。ペインを切り替えると対象も切り替わる
2. 種類を選んで「チェック開始」
   - **誤字・表記**：誤字脱字、変換ミス、表記ゆれ
   - **内容も確認**：上に加えて、事実の誤り（年号・用語など）を「要確認」として指摘
3. 対象：選択範囲があればその範囲、なければノート全体（フロントマターは除く。最大 20,000 文字）
4. 結果は指摘の一覧。1件ごとに 種類バッジ・「元の文字 → 修正案」・理由・［採用］［無視］
   - 項目クリック → 該当箇所を選択
   - チェック結果はノートごとに保持する（ペインやノートを切り替えて戻っても残る。アプリを閉じると消える）
   - 編集モードの本文には波線（誤字＝赤、表記＝青、要確認＝橙）。マウスを乗せると修正案と［採用］［無視］
   - 「誤字・表記をすべて採用」ボタン（要確認は一括採用しない）
5. Esc または × で閉じる

### 8.2 チャット
- AIパネルの「チャット」タブで、AIに自由に質問できる
- 「表示中のノートを参照」にチェックがあると、アクティブなペインのノート本文を一緒に送る（最大 20,000 文字）
- ワンタッチボタン：「要約して」「わかりやすく説明」「確認問題を作って」「重要語句を挙げて」。確認問題の答えは `==答え==` で返させるので、そのまま暗記モードで使える
- 回答はMarkdownで表示し、［ノートに挿入］（カーソルの位置。置いていなければ末尾）と［コピー］ができる
- 会話はアプリを閉じるまで保持。パネル上部の［履歴をクリア］で消去できる。送信に失敗した質問は次の履歴に含めない
- Enter で送信、Shift+Enter で改行。日本語変換中の Enter では送信しない

### 8.3 守るルール
- AIが本文を直接書き換えることはない。必ず人が採用する
- `==` `[[ ]]` `![[ ]]` `{{ }}` などの記法を変える提案はアプリ側で捨てる
- 本文が送信後に変わっていたら、その指摘は「位置が見つかりません」として採用不可にする
- 初回のみ「ノートの内容が選んだAIサービスに送信されます」と確認する（チェック・チャット共通）
- 画像は送らない
- AIを設定しなくても、アプリの他の機能はすべて使える

### 8.4 対応サービス

| サービス | 接続方式 | 既定モデル（設定で変更可） |
| --- | --- | --- |
| OpenAI | Chat Completions（`https://api.openai.com/v1`） | `gpt-5.6-luna` |
| DeepSeek | OpenAI互換（`https://api.deepseek.com`） | `deepseek-flash` |
| Google Gemini | generateContent（`https://generativelanguage.googleapis.com/v1beta`） | `gemini-3.5-flash-lite` |
| Anthropic Claude | Messages API（`https://api.anthropic.com/v1`） | `claude-haiku-5-5` |
| OpenAI互換（カスタム） | 接続先URLを自分で指定 | 自分で入力 |

- **モデル一覧の更新**：設定画面の［一覧を更新］で、選んだサービスに問い合わせて使えるモデルを取得し、プルダウンに表示する。モデルはすぐ新しくなるため、上の表の既定モデルは「一覧を取得していないときの初期値」にすぎない
  - OpenAI / DeepSeek / カスタム：`GET {接続先}/models`（埋め込み・音声・画像生成などの文章用でないモデルは除く）
  - Gemini：`GET /v1beta/models`（`generateContent` に対応したものだけ）
  - Claude：`GET /v1/models`
  - 取得した一覧と取得日時は settings.json に保存し、全件をプルダウンで選べる。末尾の「その他（モデル名を手入力）」で一覧にないモデル名も指定できる
- 応答はJSON：`{"issues":[{"kind":"typo|style|fact","original":"…","suggestion":"…","reason":"…"}]}`
- `original` は本文中の文字列そのまま（一意になるよう前後の文字を含めてよい）。アプリは本文中を検索して位置を決める
- 通信はRust側で行う（APIキーを画面側のコードに渡さない）。タイムアウト：チェック 60秒、チャット 120秒、一覧取得 30秒

### 8.5 APIキー
- Windowsの資格情報マネージャーに保存（サービス名 `StudyNotes`、アカウント名 = サービスID）
- 設定画面には「保存済み」とだけ表示し、キー自体は再表示しない。「接続テスト」ボタンあり

## 11. データとファイル構成

```
<ノートフォルダ>/
├─ 英語/単語_Unit1.md
├─ attachments/            画像
└─ .studynote/
   └─ workspace.json      画面の状態・ピン留め・最近のノート（消しても再作成）
```

## 12.1 競合コピーの検出

同期アプリ（Dropsync・FolderSync・OneDrive・Syncthing など）は、PCとスマホで同じファイルが同時に変更されると、片方を別名で残す（競合コピー）。これを見つけて解決できるようにする。

| 形式 | 例 |
| --- | --- |
| Dropbox | `ノート (Taro's conflicted copy 2026-11-26).md`、`ノート (Taro の競合コピー 2026-11-26).md` |
| OneDrive | `ノート-DESKTOP-AB12CD.md`（末尾にPC名。同じフォルダに元のファイルがあり、PC名らしい場合だけ） |
| Syncthing | `ノート.sync-conflict-20261126-123456-ABCDEF1.md` |
| そのほか | 名前に conflict／競合 を含むもの |

- 起動時と、フォルダに変更があったときに調べ、新しく見つかったら通知する
- エクスプローラー上部に「⚠ 競合コピーが n件 あります」、ツリーの行に「競合」の印
- 確認画面：一覧 → 比べる（行ごとの差分。−元のノートだけ／＋競合コピーだけ。画像は並べて表示）
- 操作：［競合コピーを採用］（元のファイルはごみ箱へ移し、競合コピーを元の名前にする）／［競合コピーを削除］／［競合ではない］（誤判定を無視リストへ）／［開く］

## 13. Android 版（スマホ）

PC 版と同じソースから作る、機能を絞った版。

| 項目 | 内容 |
| --- | --- |
| 配布 | APK（Releases に添付）。署名の鍵は GitHub Secrets（`ANDROID_KEY_BASE64`・`ANDROID_KEY_PASSWORD`）。同じ鍵なので上書き更新できる |
| 画面 | 1パネル。エクスプローラーは ☰ で左から引き出す。書式バーは1行で横スクロール。ステータスバーなし |
| 機能 | 編集（ライブプレビュー）、暗記、リンク、バックリンク、画像（表示・貼り付け・取り込み・大きさ変更）、検索、全文検索 |
| ないもの | AI、2画面、ショートカット中心の操作 |
| ノートフォルダ | アプリ内のフォルダ選択画面で選ぶ（Dropsync などの同期フォルダを想定。例：`/storage/emulated/0/Dropsync/…`） |
| 権限 | 「すべてのファイルへのアクセス」（Android 11 以降）。未許可なら起動時に設定画面を開く。Android 10 以前はストレージの読み書き権限 |
| 戻るボタン | ダイアログ → 引き出し → 暗記モード の順に閉じ、それ以外は前のノートに戻る |
| 削除 | Android にはごみ箱がないので、ノートフォルダ内の `.studynote/trash/` に移す |
| 同期 | アプリは同期しない。Dropsync 等がフォルダを同期し、アプリはフォルダの変更を監視して反映する |
